---
name: Vendor fee policy
description: Financial meaning, introductory clock and agreed vendor-specific plans.
---

The fee is Free Spirit's share, not the vendor's earnings. Explain the amount the
vendor keeps. An introductory clock starts on first publication, not approval;
before publication, introductory eligibility has not expired.

**Why:** The user clarified the financial direction and requires newly approved,
unpublished vendors to receive the introductory rate rather than the standard one.

**How to apply:** Reuse one calculation for displayed fees and newly created
booking snapshots. Never change the original publication timestamp when editing
a plan or republishing. Never recalculate existing booking snapshots.

Admin-reviewed introductory rate, months and standard rate are saved together as
the vendor's agreed plan, even when the admin accepts the global defaults.

**Why:** The user approved reviewing and overriding all three values at approval.
Future global edits should not silently replace that saved vendor-specific plan.

**How to apply:** Existing vendors without a plan still inherit global defaults.
Keep existing legacy flat overrides until an admin explicitly replaces them.
