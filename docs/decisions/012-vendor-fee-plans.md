# Introductory fees before first publication

An unstarted introductory period uses its introductory rate, without creating a
start timestamp. Approval saves the reviewed three-part vendor plan. Only first
publication starts its clock. Existing flat overrides are preserved until an
admin explicitly saves a replacement plan.

Why: The old helper required an existing publication timestamp to qualify for
introductory pricing, so new vendors incorrectly fell through to the standard
rate. A flat override cannot represent custom introductory and standard phases.
