# Decisions

Architecture Decision Records. One file per decision, numbered in order, never renumbered.

## Rules

- Write an ADR when a choice is expensive to reverse, or when a reasonable engineer would ask "why is it like this".
- ADRs are append-only. To change a decision, write a new ADR and mark the old one `superseded by <NNNN>`.
- Keep each ADR to one page. Copy `0000-template.md`.
- Existing projects: record the three to five decisions that shape daily work, from memory, with today's date and a note that they are retrospective. Do not try to reconstruct history.
