# How to request changes to Free Spirit

For Sudeshi, and anyone else asking the Replit Agent for changes. You don't need to know any
technical terms. The agent follows the same safe process for every request.

## 1. Ask in your own words

Describe what you want and why. For example:

> Vendors should be able to add up to three activities in one application. The client says
> most of them run more than one activity.

Attach screenshots or the client's document if you have them. One request at a time works best.

## 2. The agent replies with three things

- **What I understood:** check this carefully. If it's wrong, say so.
- **Category:** Small fix, Feature or Risky.
- **Next:** what happens next.

## 3. Approve, or forward to Madushan

| Category | What you do |
|---|---|
| **Small fix** (wording, layout, a simple bug) | Reply **go ahead** |
| **Feature** (something new or changed in one area) | Read the summary it shows you. Reply **Approved**, or say what to change |
| **Risky** (database, prices, commission, payments, logins, permissions, ID documents, deleting anything, new services) | The agent gives you a short message **For Madushan**. Send it to him. When he replies, paste his answer back starting with **Madushan approved:** |

The agent will not start building a Risky change until Madushan has approved it, even if it's
urgent. That rule is there to protect real customers' and vendors' data and money.

## 4. Wait for the report

When the agent finishes, it sends a short summary and one of:

- **Ready to publish: Yes** means you can publish.
- **Ready to publish: No** means it explains why. Usually Madushan needs to do something first.
  Forward the message to him.

## 5. Publishing

1. Ask the agent: **"Can I publish?"** It checks everything and answers **OK to publish: Yes / No**.
2. If Yes, publish in Replit. Database updates happen automatically during publishing.
3. After publishing, ask: **"Check the live site."** It answers **Live site: OK / Problem**.
4. If there's a problem, or anything looks wrong to you, message Madushan. He can switch back
   to the previous version.

## Good to know

- Don't publish while the agent is still working on something. Wait for its report.
- Demo listings are hidden from the public unless an admin turns on
  **Admin > Settings > Show demo content**. Turn it on before a sales demo, and off afterwards.
- Booking requests only work when **Admin > Settings > Bookings open** is on.
- If the agent asks you something you don't know, say "ask Madushan" and forward the question.
